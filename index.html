The Idea

What is AnatoX?

AnatoX is an interactive 3D education platform that helps students understand the internal structure and function of real-world objects.

Instead of reading only static diagrams or long paragraphs, users can rotate and inspect a 3D model, tap individual components and immediately understand what each part does.

The goal is to convert theoretical learning into visual understanding.

AnatoX can initially launch with around 100 carefully selected models and gradually expand using verified community contributions.

User Experience

How AnatoX works

1

Search an Object

Users choose an object from categories such as electronics, biology, physics, mechanics or everyday technology.

2

Load the 3D Model

The model opens in an interactive viewer where users can rotate, zoom and inspect it.

3

Select a Component

Users tap any highlighted part of the object.

4

Learn Its Function

AnatoX displays the component name, function, working principle and relationship with nearby components.

5

Contribute

Users can suggest missing objects, submit models or add better explanations.

6

AI Review

AI checks for duplicates, incomplete information and possible technical errors.

7

Human Verification

High-value submissions can be verified by teachers, professors or specialists.

8

Publish & Reward

Approved contributions become part of the AnatoX library and contributors earn reputation points.

Architecture

Designed to scale.

3D models should not be stored directly inside the main database.

Recommended Storage Design

``` 
Flutter Mobile App
        │
        ▼
Backend API
        │
        ├────────────► PostgreSQL
        │               │
        │               ├── Users
        │               ├── Model metadata
        │               ├── Components
        │               ├── Reviews
        │               └── Credit points
        │
        └────────────► Cloud Object Storage
                        │
                        ├── .glb models
                        ├── thumbnails
                        └── optional media
```

GLB stands for GL Transmission Format Binary. It packages the model, materials, textures and scene information into one compact file.

Quality Control

Preventing spam and credit farming

No Instant Rewards

Uploading something alone should not generate points.

Quality-Based Rewards

More accurate and useful content should receive more reputation.

Duplicate Detection

Repeated or copied models should be automatically flagged.

Contribution Limits

New accounts can have reasonable submission limits until trust improves.

Community Reports

Users can report incorrect, misleading or poor-quality submissions.

Reputation Weighting

A trusted contributor's review can carry more weight than a brand-new account.

Updated Strategy

Important decisions for AnatoX

Do Not Build a Full 3D Editor First

A Blender-style in-app editor would make the first version far too complex. Start with viewing and interaction.

Build 10–20 Models Before 100

Test whether students actually use and enjoy the experience before investing in a huge model library.

Store Models in the Cloud

Keep GLB files in object storage and store only URLs and metadata in PostgreSQL.

Keep Models Lightweight

Optimize polygons and textures so models load quickly even on normal Android phones.

AI Assists, Humans Verify

AI can catch obvious issues, but expert-reviewed content should be used for verified educational information.

Reputation Over Raw Points

Contributor trust should depend on approval rate and quality, not just upload count.

Schools Can Become Contributors

Later, teachers and colleges could upload verified educational models and lesson content.

Offline Caching

Frequently viewed models can later be cached on-device to reduce data usage and improve loading speed.
